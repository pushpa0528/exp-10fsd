Step 1: Install MongoDB Locally Windows
1. Download MongoDB Community Server from the official MongoDB website.
2. Run the downloaded .msi installer.
3. Select Complete installation.
4. During installation, select: Install MongoD as a Service
5. Complete the installation.
6. MongoDB is normally installed in a directory similar to: C:\Program Files\MongoDB\Server\8.0\bin
The version number may be different on your computer.

Step 2: Verify MongoDB Installation
Open Command Prompt.
Run:
mongod --version

You should see output similar to:
db version v8.x.x
Build Info: ...

Then check the MongoDB Shell:
mongosh --version
Example: 2.x.x

Step 3: Start the Local MongoDB Server
If MongoDB was installed as a Windows service, open Command Prompt as Administrator and run:
net start MongoDB

If it starts successfully, you will see:
The MongoDB Server service was started successfully.

You can then connect to the local MongoDB server:
mongosh
or:
mongosh "mongodb://localhost:27017"

You should see something similar to:
Connecting to: mongodb://127.0.0.1:27017/

Step 4: Check MongoDB Version
After entering the mongosh shell, run:
db.version()
Example: 8.0.x

You can also run:
db
Output may be:
test
This means you are currently using the test database.

Exit MongoDB Shell
Exit
