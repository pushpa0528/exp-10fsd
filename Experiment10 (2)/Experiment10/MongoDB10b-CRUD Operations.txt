MongoDB Atlas – Installation, Connection and CRUD Operations
===============================================================

Student MongoDB Atlas Command Prompt / mongosh Record

1. CONNECT TO MONGODB ATLAS
---------------------------

Command:

mongosh "mongodb+srv://cluster0.v24kq43.mongodb.net/" --username student

Output:

2. SELECT THE DATABASE
----------------------

Command:

Output:

6. FIND A BOOK BY AUTHOR
------------------------

Command:

    author: "George Orwell"
})

Output:

[
  {
    _id: ObjectId('6aba204159f748effe008a77'),
    title: '1984',
    author: 'George Orwell',
    year: 1949,
    genre: 'Dystopian'
  }
]


7. FIND BOOKS PUBLISHED AFTER 1950
-----------------------------------

Command:

db.books.find({
    year: { $gt: 1950 }
})

Output:

No documents were returned.


8. UPDATE A BOOK
----------------

Command:

db.books.updateOne(
    { title: "1984" },
    { $set: { year: 1950 } }
)

Output:

{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}
